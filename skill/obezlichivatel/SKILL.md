# Обезличиватель: сначала скрыть данные, потом работать

Персональные данные пользователя не должны попадать в контекст Claude. Обезличиватель заменяет их метками
`[ФИО-1]`, `[ТЕЛЕФОН-2]` (а ID — другими ID того же вида) на компьютере пользователя, а ключ «метка → значение»
хранит у пользователя. Claude работает только с обезличенной копией.

Инструменты — у MCP-сервера `obezlichivatel` (`obezl_*`). Если их нет в списке инструментов, скажи пользователю,
что Обезличиватель не подключён: нужно запустить установщик (`install.sh` на Mac, `install.cmd` на Windows)
и перезапустить Claude Code. До этого файл с данными не открывай.

## Главное правило

Файл, где могут быть персональные данные, **никогда не читай напрямую** — ни Read, ни Bash (cat, head, python,
grep), ни Glob по содержимому. Даже чтобы «только посмотреть заголовки». Первый шаг — всегда `obezl_mask_file`.
Папки `~/Обезличиватель/Сырые`, `С данными` и `.ключи` закрыты защитным хуком — это не ошибка, обходить не нужно.

Если пользователь вставил персональные данные прямо в чат — не повторяй их в ответе. Предложи в следующий раз
класть файл в «Сырые» или копировать текст и просить «обезличь буфер обмена».

## Как получить обезличенный файл

**Файл на диске** (в «Сырые» или по пути, который назвал пользователь):
1. Нет пути — `obezl_files`: список файлов в «Сырые» (имена скрыты), №1 — самый свежий.
2. `obezl_mask_file` с номером или путём. Откроется страница проверки в браузере пользователя.
3. Скажи пользователю коротко: «Открыл страницу проверки. Посмотрите, что будет скрыто, и нажмите
   „Скрыть и отдать Claude“». Не продолжай, пока он не нажмёт.
4. `obezl_result` с номером задания (можно `wait_seconds` до 120). Получишь путь в «Обезличенные»,
   сводку и начало текста. Если задание ещё не готово — подожди и спроси снова, не открывай файл сам.

**Пользователь передал файл со страницы** («я передал файл», «нажал „Передать в Claude“»):
`obezl_masked` — список обезличенных файлов, свежие сверху. Бери самый свежий, если не назван другой.

**Текст из письма или чата**: попроси скопировать его и вызови `obezl_mask_clipboard`.

PDF и сканы тоже идут через `obezl_mask_file`: страница превратит их в текст (сканы распознаёт на Mac),
результат — `.txt` с отметками страниц.

## Как работать с обезличенным файлом

- Читай через `obezl_read`: Word — по абзацам, Excel — строками (TSV) с выбором листа, PowerPoint — по слайдам
  с заметками, текст — по строкам. Большие файлы — частями (`offset`, `limit`). Для расчётов можно писать свои
  скрипты, но только по файлам из «Обезличенные».
- Метки `[ФИО-1]`, `[ТЕЛЕФОН-3]` — это настоящие люди и номера. Не придумывай им имена, не склеивай и не
  переименовывай метки, сохраняй их в выводах как есть. Один человек везде — одна метка.
- ID (номера учеников, заявок, UUID) заменены на другие ID того же вида: число осталось числом. Связи между
  таблицами, подсчёты и группировки по ним верны. Не называй их настоящими.
- Если в сводке есть предупреждения (картинки в документе, распознанные сканы, страницы без текста) —
  передай их пользователю: эти места могли не проверяться или распознаться с ошибками.

## Как вернуть настоящие данные

Когда пользователю нужен итоговый документ с настоящими именами (письма, отчёт, таблица):
1. Сохрани результат с метками в файл: `.docx`, `.xlsx`, `.pptx`, `.md`, `.txt` или `.csv`.
2. Вызови `obezl_unmask` с путём к этому файлу.
3. Сообщи пользователю путь к файлу в «С данными». Содержимое этого файла ты не увидишь и не читай — это нормально.

Если пользователь хочет ответ прямо в чате с настоящими именами — объясни, что метки можно вернуть на странице
Обезличивателя: вкладка «Вернуть данные», вставить ответ — ключ этого компьютера подставится сам.

## Чего не делать

- Не читать файлы из «Сырые», «С данными», `.ключи` и любые файлы с данными до обезличивания.
- Не просить пользователя прислать ключ и не печатать содержимое ключа.
- Не угадывать, кто скрыт за меткой, и не «восстанавливать» данные по контексту.
- Не предлагать отключить хук или обойти проверку ради скорости.

## Примеры запросов пользователя

- «Обезличь свежий файл из Сырых и посчитай, на что чаще всего жалуются» → `obezl_files` → `obezl_mask_file 1`
  → дождаться нажатия → `obezl_result` → `obezl_read` → анализ.
- «Вот ЧТЗ ~/Downloads/ЧТЗ_журнал.docx, найди противоречия» → `obezl_mask_file` с этим путём → … → `obezl_read`.
- «Я передал выгрузку через Обезличиватель, сделай сводную по школам» → `obezl_masked` → `obezl_read`.
- «Подготовь ответы каждому заявителю в Word с их именами» → ответы с метками в `.docx` → `obezl_unmask` → путь.
