# Обезличиватель — без Claude

Скрывает персональные данные в документах: ФИО, телефоны, почту, СНИЛС, ИНН, паспорта, адреса, даты рождения,
суммы, логины, пароли, ID. Вместо них — метки `[ФИО-1]`, `[ТЕЛЕФОН-2]`. Таблица «метка → значение» (ключ)
скачивается вам. **Всё работает на этом компьютере**: ничего не устанавливается, данные никуда не отправляются.

Эта редакция — только обезличивание: никаких функций для Claude и других внешних сервисов.

Excel, Word, PowerPoint, PDF, CSV, логи, текст. Сканы и скриншоты — на Mac.

---

## Как запустить

Распакуйте архив в любую папку (права администратора не нужны).

| | Как открыть | Что работает |
|---|---|---|
| Просто страница | Дважды щёлкнуть `Обезличиватель.html` (Chrome, Edge, Яндекс Браузер, Safari) | Быстрая проверка: шаблоны и словарь |
| Mac | Дважды щёлкнуть `Запустить на Mac.command`. Если Mac скажет «не удаётся проверить разработчика» — правой кнопкой → «Открыть» | Плюс глубокая проверка через Ollama и распознавание сканов |
| Windows | Дважды щёлкнуть `Запустить на Windows.cmd` | Плюс глубокая проверка через Ollama |

Для запуска через `Запустить…` нужен Python 3.8+ (на Mac — «инструменты разработчика» или python.org,
на Windows — python.org). Нет Python — откроется просто страница.

## Глубокая проверка (Ollama)

Обезличиватель **сам ищет Ollama на этом компьютере** и, если она установлена, запускает её и берёт уже скачанную
модель (лучше всего `qwen3:8b`, подойдёт и другая). Он ничего не скачивает и не устанавливает.

Если Ollama нет, а глубокая проверка нужна (на рабочем компьютере — по согласованию с ИБ):
1. Установите Ollama с ollama.com.
2. В терминале: `ollama pull qwen3:8b` (около 5 ГБ; на слабом компьютере — `qwen3:4b`).
3. На странице: «Как проверять» → «Глубокая» → «Проверить снова».

Глубокая проверка: модель читает текст целиком, находит пропущенное («Колян», «двенадцать миллионов рублей»)
и снимает лишнее («модуль «Корзина»», «диаграмма Ганта»). Около 10 секунд на страницу текста.

## Как пользоваться

1. Выберите, как проверять: **Глубокая** или **Быстрая**.
2. Перетащите файл (можно несколько — метки будут общими) или вставьте текст.
3. Проверьте, что будет скрыто: нажмите на лишнее, чтобы оставить; выделите пропущенное, чтобы скрыть.
4. **«Скрыть»**. Обезличиватель сам проверит результат: если что-то осталось — покажет и предложит «Скрыть и их».
5. **«Скачать файл»** — обезличенная копия. **«Скачать ключ»** — себе. **«Отчёт для ИБ»** — что и сколько скрыто,
   без самих данных.

**Вернуть данные.** Вкладка «Вернуть данные»: выберите ключ и файл или текст с метками → «Вернуть данные».

**Важно:** в ключе настоящие данные — храните его у себя и не пересылайте вместе с обезличенным файлом.

## Что внутри

| Файл | Зачем |
|---|---|
| `Обезличиватель.html` | Вся страница в одном файле. Не обращается к интернету — это запрещено её настройками безопасности |
| `local_server.py` | Маленький сервер на 127.0.0.1: показывает страницу, находит и запускает Ollama, передаёт ей текст. Ничего не хранит, сам закрывается через 2 часа |
| `llm.py` | Запросы к Ollama и проверка её ответов |
| `ocr-macos` | Распознавание сканов встроенным в macOS Apple Vision |
| `Запустить на Mac.command`, `Запустить на Windows.cmd` | Запуск одним щелчком |

Это не сертифицированное средство защиты информации. Перед использованием на реальных данных согласуйте с ИБ.
