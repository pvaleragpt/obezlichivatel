# Обезличиватель для Claude

Скрывает персональные данные в файлах **до того, как их увидит Claude**: ФИО, телефоны, почту, СНИЛС, ИНН,
паспорта, адреса, даты рождения, суммы, логины, пароли, ID. Вместо них — метки `[ФИО-1]`, `[ТЕЛЕФОН-2]`.
Таблица «метка → настоящее значение» (ключ) остаётся у вас. Всё считается на вашем компьютере, без интернета.

Работает с Excel, Word, PowerPoint, PDF (и сканами — на Mac), CSV, логами и текстом.

---

## Установка

**Mac.** Распакуйте архив. Откройте «Терминал» (Cmd+Пробел → «Терминал»), напечатайте `bash ` (с пробелом),
перетащите в окно файл `install.sh` и нажмите Enter. Если Mac попросит «инструменты разработчика» — согласитесь
и повторите.

**Windows.** Распакуйте архив и дважды щёлкните `install.cmd`. Нужен Python 3.8+ с python.org
(при установке — галочка «Add python.exe to PATH»).

Установщик:
- подключает Обезличиватель к Claude Code (MCP-сервер `obezlichivatel`);
- ставит **скилл** `obezlichivatel` — Claude сам понимает, что файл с данными сначала надо обезличить;
- ставит **защитный хук** — Claude не сможет прочитать папки с настоящими данными никаким способом;
- создаёт папку `~/Обезличиватель` и ярлык «Обезличиватель» на Рабочем столе.

После установки **перезапустите Claude Code**.

## Три способа работать с Claude

### 1. Попросить Claude — он сам вызовет Обезличиватель

Положите файл в `~/Обезличиватель/Сырые` (или просто назовите путь) и напишите в Claude Code:

> Обезличь свежий файл из Сырых и посчитай, на что чаще всего жалуются.

> Вот ЧТЗ ~/Downloads/ЧТЗ_журнал.docx — обезличь и найди противоречия в требованиях.

Что происходит:
1. Claude открывает у вас в браузере **страницу проверки**: видно, что будет скрыто.
2. Вы смотрите, при необходимости снимаете лишнее (нажать на подсвеченное) или добавляете пропущенное
   (выделить мышью), и жмёте **«Скрыть и отдать Claude»**.
3. Claude получает только обезличенную копию и работает с ней.

### 2. Со страницы — кнопкой «Передать в Claude»

Откройте ярлык «Обезличиватель», перетащите файл, проверьте, нажмите **«Скрыть»** → **«Передать в Claude»**.
Страница даст готовый запрос — вставьте его в любой чат Claude Code на этом компьютере:

> Я передал обезличенный файл «отчёт (обезличено).docx» через Обезличиватель. Найди его (obezl_masked) и прочитай (obezl_read), затем …

### 3. Текст из письма или чата

Скопируйте текст и скажите Claude: **«обезличь буфер обмена»**. Или вставьте текст на странице во вкладку
«Текст» и скопируйте результат.

## Как получить документ с настоящими именами

Claude отвечает с метками: «[ФИО-3] просит перезвонить». Вернуть имена можно двумя способами:

- **В файл.** Попросите: «Сделай письмо-ответ каждому заявителю в Word и верни в него данные». Claude сохранит
  документ с метками и вызовет возврат — файл с настоящими данными появится в `~/Обезличиватель/С данными`.
  Claude его содержимое не увидит.
- **В текст.** Откройте страницу → вкладка «Вернуть данные» → вставьте ответ Claude → «Вернуть данные».
  Ключ этого компьютера подставится сам.

## Быстрая и глубокая проверка

На первом шаге страницы — выбор:
- **Глубокая (рекомендуем)** — локальная модель (Ollama) читает текст целиком: находит пропущенное
  («Колян», «двенадцать миллионов», подрядчик без «ООО») и снимает лишнее («модуль «Корзина»», «диаграмма Ганта»).
  Около 10 секунд на страницу. В первый раз нажмите «Подключить» — Ollama и модель скачаются (около 3,5 ГБ).
- **Быстрая** — шаблоны и словарь, секунды. Может скрыть лишнее или пропустить необычное.

После «Скрыть» Обезличиватель сам проверяет готовый файл: если какое-то значение где-то осталось — покажет его
и предложит «Скрыть и их». Кнопка **«Отчёт для ИБ»** — что и сколько скрыто, без самих данных.

## Правила

- Файлы с персональными данными кладите в `~/Обезличиватель/Сырые` — оттуда Claude читать не может.
- **Ключ никому не пересылайте и в Claude не отправляйте** — в нём настоящие данные.
- Метки `[ФИО-1]` — это реальные люди. Один человек во всех файлах — одна метка.
- ID (номера учеников, заявок, UUID) заменяются другими ID того же вида — подсчёты и связи остаются верными.
- Автоматический поиск не идеален. **Проверка на странице перед отправкой — обязательный шаг.**

## Чего не умеет

- Картинки внутри Word и PowerPoint не проверяются (страница предупредит, сколько их).
- Сканы распознаются только на Mac (Apple Vision); распознанный текст проверяйте особенно внимательно.
- Старые форматы `.doc`, `.xls`, `.ppt` — пересохраните в `.docx`, `.xlsx`, `.pptx`. Файлы под паролем не открываются.

## Если что-то не работает

- **Claude не видит инструменты `obezl_*`** — перезапустите Claude Code; если не помогло, запустите установщик ещё раз.
- **Страница не открылась** — откройте ярлык «Обезличиватель» или ссылку, которую дал Claude.
- **Глубокая проверка «не подключена»** — на странице: «Как проверять» → «Глубокая» → «Подключить».

Подробности устройства — в «Техническое описание.md».
